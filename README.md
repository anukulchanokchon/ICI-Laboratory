# ICI-Laboratory · LabTrace

ระบบต้นแบบติดตามการยืม ใช้ และคืนอุปกรณ์/สารเคมีในห้องปฏิบัติการเคมีอุตสาหกรรม

## เริ่มทำงานกับซอร์สโค้ด

ต้องใช้ Node.js 22.13+ และสำหรับสคริปต์ build ในชุดนี้ต้องใช้ Linux ที่มี bash และ GNU timeout

```bash
npm ci
npm run dev
```

เว็บเปิดพัฒนาในเครื่องตาม URL ที่คำสั่งแสดง ตรวจสอบผลสร้างด้วย `npm run build` และเริ่มงานจากผลสร้างด้วย `npm run start`

- `app/page.tsx` หน้าจอและการทำงานหลัก
- `app/globals.css` การจัดวางและสี
- `public/` รูปและไอคอน
- `worker/`, `vite.config.ts`, `package.json` และ `package-lock.json` ส่วนเริ่มโปรเจกต์ Vinext/Cloudflare Workers

## สถานะก่อนใช้จริง

นี่เป็นต้นแบบที่ทำหน้าตาและขั้นตอนหลักไว้แล้ว **ยังไม่ใช่ระบบบัญชีและฐานข้อมูลกลางสำหรับนักศึกษาจริง** ตอนนี้ ID ใดก็เข้าสู่ระบบด้วยรหัสเริ่มต้น `000000` ได้ การเปลี่ยนรหัสผ่าน การล็อกหลังกรอกผิด 5 ครั้ง และบางประวัติเก็บในเบราว์เซอร์เครื่องนั้นเท่านั้น ล้างข้อมูลเว็บไซต์แล้วรหัสที่เปลี่ยนจะหายไป หลายหน้ามีข้อมูลตัวอย่าง รายชื่อและชั้นปียังรอข้อมูลจริง เบอร์/Instagram/QR LINE สำหรับหน้าลืมรหัสผ่านยังเป็นช่องรอข้อมูล

ก่อนเปิดให้ใช้งานจริง ให้เชื่อมระบบยืนยันตัวตนฝั่งเซิร์ฟเวอร์และฐานข้อมูลกลางที่กำหนดบัญชีนักศึกษา/อาจารย์และผู้ดูแล เก็บรหัสผ่านที่แฮชแล้วบนเซิร์ฟเวอร์ บันทึกกิจกรรมและลายเซ็นในฐานข้อมูล และทำรายงานรวมที่ตรวจสิทธิ์ผู้ดูแลก่อนส่งออก ไม่ควรเก็บหรือส่งออกรหัสผ่านจริง

## GitHub และเว็บจริง

การอัปโหลดซอร์สขึ้น GitHub ทำให้เก็บและจัดการโค้ดได้ แต่ไม่ได้ทำให้โปรเจกต์นี้เปิดเป็นเว็บจาก GitHub Pages โดยตรง เพราะชุดนี้ใช้ Vinext/Cloudflare Worker ไม่ใช่เว็บ static HTML ล้วน หากจะใช้ GitHub Pages ต้องแปลงเป็นเว็บ static และระบบบัญชี/ข้อมูลส่วนกลางต้องมีบริการแยกต่างหาก สำหรับเว็บที่ต้องรับข้อมูลผู้ใช้ แนะนำโฮสต์ Worker พร้อมฐานข้อมูลและสิทธิ์บัญชีที่เหมาะสม
